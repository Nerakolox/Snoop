### 任务 A · 开发模式放行右键菜单（先做，否则你后面调 CSS 会瞎）

**文件**：`src/main.tsx:17`

**现状原文**：

```ts
// 禁用 webview 默认右键菜单，让 App 更像原生程序（Ctrl+C/V 依然可用）
window.addEventListener("contextmenu", (e) => e.preventDefault());
```

**问题**：这行把 macOS webview 的「检查元素」入口一起封了，导致 `tauri dev` 下打不开
devtools、看不到 console。后续所有样式工作都要靠它。

**改成**：

```ts
// 禁用 webview 默认右键菜单，让 App 更像原生程序（Ctrl+C/V 依然可用）。
// 开发模式放行，保留「检查元素」入口——否则 devtools 打不开，console 也看不到。
// import.meta.env.DEV 在打包产物里恒为 false，发布行为不变。
window.addEventListener("contextmenu", (e) => {
  if (import.meta.env.DEV) return;
  e.preventDefault();
});
```

**验收**：
- `npx tsc --noEmit` 通过（`import.meta.env.DEV` 是 Vite 内置类型，无需额外声明；若报错说明 `tsconfig.json` 缺 `vite/client` types，**报告给我，不要自己改 tsconfig**）
- `npm run tauri dev` 起来后右键能出菜单、能开检查元素

**commit**：`fix(dev): 开发模式放行右键菜单，恢复 devtools 入口`

### 任务 B · 消灭 6 处 `@media (prefers-color-scheme: dark)`

这是本单的主体。**注意：不是无脑删。这 6 处分两类，改法不同。**

先自己跑一遍确认位置（行号可能因任务 A 而未变，但仍以 grep 为准）：

```bash
grep -rn "prefers-color-scheme" src/styles/
```

预期命中 6 条：`base.css` 5 条 + `settings.css` 1 条。
（`src/main.tsx` 与 `src/pages/Settings.tsx` 里的 `matchMedia("(prefers-color-scheme: dark)")`
是 **JS 读系统主题**，是正确且必需的，**绝对不要动**。）

#### B-1：纯重复的 2 处 —— 直接删除整个 media 块

这两处的**下一条规则**就是等价的 `[data-theme="dark"]` 版本，media 块是纯冗余。

**① `src/styles/base.css`（约 :185）**

删掉这一整块：

```css
@media (prefers-color-scheme: dark) {
  .sidebar {
    background: rgba(43, 39, 49, 0.8);
    border-right-color: rgba(255, 255, 255, 0.08);
  }
}
```

保留紧随其后的 `[data-theme="dark"] .sidebar { ... }` 与 `[data-theme="light"] .sidebar { ... }`，
两者内容一字不改。

**② `src/styles/settings.css`（约 :351）**

删掉这一整块（连同上面那行英文注释）：

```css
/* dark mode overrides for toggle thumb */
@media (prefers-color-scheme: dark) {
  .setting-toggle-thumb {
    background: rgba(255, 255, 255, 0.9);
  }
}
```

保留紧随其后的 `[data-theme="dark"] .setting-toggle-thumb { ... }`，内容一字不改。

#### B-2：没有双胞胎的 4 处 —— 改写选择器，**不要删**

这 4 处**没有**对应的 `[data-theme="dark"]` 规则。直接删会丢掉深色模式样式。
改法统一为：**去掉 `@media` 包裹，给每条选择器加 `[data-theme="dark"] ` 前缀，声明内容一字不改。**

**③ `src/styles/base.css`（约 :149）滚动条**

改前：

```css
@media (prefers-color-scheme: dark) {
  .app-main:hover,
  .app-main:focus-within,
  .scroll-area:hover,
  .scroll-area:focus-within {
    scrollbar-color: rgba(240, 237, 232, 0.28) transparent;
  }

  .app-main:hover::-webkit-scrollbar-thumb,
  .app-main:focus-within::-webkit-scrollbar-thumb,
  .scroll-area:hover::-webkit-scrollbar-thumb,
  .scroll-area:focus-within::-webkit-scrollbar-thumb {
    background-color: rgba(240, 237, 232, 0.2);
  }

  .app-main::-webkit-scrollbar-thumb:hover,
  .scroll-area::-webkit-scrollbar-thumb:hover {
    background-color: rgba(240, 237, 232, 0.4);
  }
}
```

改后：

```css
[data-theme="dark"] .app-main:hover,
[data-theme="dark"] .app-main:focus-within,
[data-theme="dark"] .scroll-area:hover,
[data-theme="dark"] .scroll-area:focus-within {
  scrollbar-color: rgba(240, 237, 232, 0.28) transparent;
}

[data-theme="dark"] .app-main:hover::-webkit-scrollbar-thumb,
[data-theme="dark"] .app-main:focus-within::-webkit-scrollbar-thumb,
[data-theme="dark"] .scroll-area:hover::-webkit-scrollbar-thumb,
[data-theme="dark"] .scroll-area:focus-within::-webkit-scrollbar-thumb {
  background-color: rgba(240, 237, 232, 0.2);
}

[data-theme="dark"] .app-main::-webkit-scrollbar-thumb:hover,
[data-theme="dark"] .scroll-area::-webkit-scrollbar-thumb:hover {
  background-color: rgba(240, 237, 232, 0.4);
}
```

> ⚠️ `data-theme` 设在 `<html>` 上，`.app-main` / `.scroll-area` 是它的后代，
> 所以**后代选择器（空格）正确**。不要写成 `[data-theme="dark"].app-main`（无空格 = 同一元素，永不命中）。
> 这条对下面 ④⑤⑥ 同样适用。

### 任务 C · `tokens.css` 的 `:root` 幽灵色板

**文件**：`src/styles/tokens.css:6-26`

**问题**：`:root` 里那套**偏暖的奶油白色板**（`--color-bg: #FAF8F5`、`--color-border: #E8E3D9` 等）
**从来没有生效过**——`main.tsx` 在渲染前恒会设 `data-theme`，`[data-theme="light"]`（冷灰紫，
`--color-bg: #F5F4F7`）与 `[data-theme="dark"]` 完整覆盖了 `:root` 的**全部 14 个颜色 token**
（accent×4 + 中性×7 + intensity×5，已逐个比对确认无遗漏）。

结果就是 tokens.css 里躺着第三套永不生效的色板，读代码的人（包括你）会被误导。

**改法**：把 `:root` 里这 14 个颜色 token 的值**改成与 `[data-theme="light"]` 完全一致**，
并加注释说明它是 fallback。**不要删除 `:root` 的这些声明**——保留它作为 `data-theme`
万一缺失时的兜底，比全站变成无色好。

具体：`src/styles/tokens.css` 中 `:root` 内的这一段

```css
  /* 品牌色（交互/身份：导航选中、按钮、链接） */
  --color-accent:        #6D5AE6;
  --color-accent-hover:  #5B48D4;
  --color-accent-soft:   #ECE9FB;
  --color-on-accent:     #FFFFFF;

  /* 中性 —— 背景 / 表面 / 边框 / 文字 */
  --color-bg:            #FAF8F5;
  --color-surface:       #FFFFFF;
  --color-surface-2:     #F3F0EA;
  --color-border:        #E8E3D9;
  --color-text:          #2A2730;
  --color-text-2:        #6B6670;
  --color-text-3:        #9B96A0;

  /* 强度色阶（数据表达：键鼠活跃度低→高） */
  --intensity-0:         #D9D5CE;
  --intensity-1:         #F2D98C;
  --intensity-2:         #F5B841;
  --intensity-3:         #EE8B3D;
  --intensity-4:         #E15A4C;
```

替换为

```css
  /* ⚠️ 以下颜色是 fallback，正常情况下永远被 [data-theme="light"] / [data-theme="dark"]
     完整覆盖（src/main.tsx 在渲染前恒会给 <html> 设 data-theme）。
     取值刻意与 [data-theme="light"] 保持一致——改色板请改下面两个 data-theme 块，
     改这里不会有任何效果。 */

  /* 品牌色（交互/身份：导航选中、按钮、链接） */
  --color-accent:        #6C5CE7;
  --color-accent-hover:  #7D6EF0;
  --color-accent-soft:   #EDE9FF;
  --color-on-accent:     #FFFFFF;

  /* 中性 —— 背景 / 表面 / 边框 / 文字 */
  --color-bg:            #F5F4F7;
  --color-surface:       #FFFFFF;
  --color-surface-2:     #F0EEF3;
  --color-border:        #E2DFE8;
  --color-text:          #1A1820;
  --color-text-2:        #5C5868;
  --color-text-3:        #9B96A4;

  /* 强度色阶（数据表达：键鼠活跃度低→高） */
  --intensity-0:         #E8E5EE;
  --intensity-1:         #D4A843;
  --intensity-2:         #E09030;
  --intensity-3:         #E07030;
  --intensity-4:         #D94438;
```

**同时**：`:root` 里的 `--shadow-sm` / `--shadow-md` 也同样被两个 data-theme 块覆盖，
**但本次不动它们**（值差异小、改了增加 diff 噪音）。只在它们上方补一行注释：

```css
  /* 阴影（同样被 data-theme 块覆盖，此处为 fallback） */
```

**不要改**：`--radius-*` / `--space-*` / `--text-*` / `--ease-*` / `--dur-*` /
`--sidebar-width` / `--traffic-light-inset` / `font-family` 等 —— 这些**只在 `:root` 定义**，
data-theme 块不覆盖，是真正生效的，动了会出事。

**验收**：改完全站视觉**必须零变化**（因为改的值本来就不生效）。
在 `tauri dev` 里浅色/深色各扫一眼，任何一处颜色变了都说明判断有误，**立即回滚并报告**。

**commit**：`refactor(tokens): :root 幽灵色板对齐 light 主题并标注 fallback`
